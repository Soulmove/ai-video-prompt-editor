# 镜序 2.0 · 多轨时间轴 AI 视频提示词剪辑台 (`ai-video-prompt-editor`)

> **像用剪映 / Premiere 一样，从 `00:00` 空白时间轴可视化剪辑 AI 视频提示词——100% 无需 AI 接口或密钥，纯本地手工掌控每一帧分镜、跨镜 J-Cut 对白、音效与调节层。**

🌐 **在线免安装体验地址**：https://soulmove.github.io/ai-video-prompt-editor/  
🔗 **姐妹项目（镜序 1.0 · 结构化分镜与 AI 导演流水线）**：https://github.com/Soulmove/ai-video-prompt-studio

## 一、 为什么推出镜序 2.0？（从「写表填坑」进化为「时间轴非线性剪辑」）

随着国产与国际新一代原生音画视频模型（Seedance / Kling / Sora / Runway / Veo / Wan / Hailuo）陆续支持**多镜头叙事、同声口型、环境音与精确起止控制**，创作者越来越需要真正站在**剪辑师与导演视角**下统筹全局，而不是把时间切碎在分散文本框里。

| 维度 | [镜序 1.0 (`ai-video-prompt-studio`)](https://github.com/Soulmove/ai-video-prompt-studio) | **镜序 2.0 (`ai-video-prompt-editor`)** |
| :--- | :--- | :--- |
| **核心形态** | 四步创作向导（立项 → 人物场景 → 分镜表 → 汇总导出），内置可选 AI 导演辅助 | **剪映式五轨可视化 NLE 时间轴工作台**，专为精确时序剪辑而生 |
| **开局状态** | 提供项目模版与可选大模型接口生成 | **严格从 `00:00` 空白时间轴起剪，0 AI 依赖**，本地点选拖拽即可成片 |
| **声音与字幕** | 从属于单张分镜卡片内部属性 | **独立 `T1 对白轨` / `A1 音效轨` / `A2 配乐轨`**，支持真实 **J-Cut / L-Cut 跨镜叠音**与人声避让 |
| **全局风格覆盖** | 单镜逐项选填 | 新增 **`E1 调节层轨 (Adjustment Layer)`**，拉条即统一覆写区间内多个镜头的影调、光影与慢动作修饰 |
| **工程互通** | 导出 `.jingxu.json` 工程档案 | **原生双向兼容读取 1.0 `.jingxu.json`**，一键自动拆解转入 2.0 五轨时间轴！ |

> **给未来视频模型的提前基础设施**：目前多轨精确切片（`00:03.5 -> 00:04.0` 声画交错、对白防穿帮、调节层继承）的设计比当前多数消费级视频模型更超前；当未来 1–2 年内全多模态长镜头与音画编排接口彻底普及，这套时间轴工程可直接成为标准编剧与制片工程文件。

## 二、 核心功能亮点

1. **五轨专业非线性时间轴（NLE）**
   - **`E1 调节层轨`**：像剪映调节层一样横跨多个 V1 镜头，集中覆写画风美学、胶片色彩、主光源与慢快门修饰。
   - **`V1 主视频 / 分镜轨`**：拖拽调换顺序、左右边缘无损裁剪时长（最短 `0.5s`）、切点 `⇄` 胶囊直接调用 **110 种电影感转场**；支持开启 **🔗 主轨联动（Ripple）** 自动紧贴或关闭留白。
   - **`T1 对白 / 字幕轨`**：自由拖拽起止点覆盖两个相邻镜头，轻松实现 **J-Cut（未见其人先闻其声）** 或 **L-Cut**。
   - **`A1 音效 / 环境轨`**：重叠音效自动错层排列，精确到 `0.1s` 标尺触发。
   - **`A2 配乐 / BGM 轨`**：内置 **Audio Ducking（人声避让压低）** 标记，编译时自动提醒模型压低配乐突出人声。

2. **三栏专业剪辑布局 + 节目监视器**
   - **左侧素材积木库**：预设空白块、运镜积木、写实风格块、对白音效配乐积木一点落轨；角色定妆卡（含自然五官预设防整容脸）与场景空间锚点可复用绑定。
   - **中央节目监视器**：实时按 `16:9` / `9:16` / `2.39:1` / `1:1` 等画幅渲染取景框、上传参考图预览、活跃调节层徽章、音频避让提示与底部实时同步对白字幕，支持 `Space` 空格键实时播放与红线 Scrub。
   - **右侧上下文检视与编译器**：随时在 **分镜汇总 (`storyboard`)**、**时间切片 (`timeline` - 自动切出跨轨 J-Cut 边界)**、**仅当前片段 (`selected`)**、**精简 (`concise`)** 与 **CSV 分镜剪辑表 (`table`)** 之间切换，一键导出中/英双语提示词、`.txt` 或 `.csv`。

3. **极致轻量：零第三方运行时依赖 & 纯本地 IndexedDB 自动存档**
   - 前端纯原生 HTML5 / CSS3 / ES Modules，服务端仅 1 个轻量 Node.js 20+ 原生 HTTP 模块。
   - 所有工程、图片（客户端压缩存储）均存在你的浏览器本地 `IndexedDB` 中，断网亦可流畅使用。

## 三、 快捷键一览

| 快捷键 | 功能 |
| :--- | :--- |
| `Space` | 播放 / 暂停节目监视器 |
| `B` 或 `S` | **剃刀工具**：在红色播放头位置将 V1/T1/A1/A2/E1 片段一刀两段 |
| `←` / `→` | 微调红色播放头 `±0.2s`（按住 `Shift` 为 `±1.0s`） |
| `Delete` / `Backspace` | 删除当前选中的片段 |
| `Ctrl + Z` | 撤销（最多保留 60 步历史） |
| `Ctrl + Y` / `Ctrl + Shift + Z` | 重做 |

## 四、 本地运行与一键启动

### 环境要求
- **Node.js >= 20.0.0**（零 `npm install` 第三方包依赖）

### 启动命令

```bash
git clone https://github.com/Soulmove/ai-video-prompt-editor.git
cd ai-video-prompt-editor
npm start
```

Windows 用户也可直接双击根目录 **`启动镜序2.0工作台.bat`**，将自动拉起本地服务（`http://127.0.0.1:4174/`）并打开浏览器。

### 验证测试

```bash
npm run check   # 语法静态校验所有模块
npm test        # 运行 NLE 引擎核心单元测试 (node --test)
npm run build   # 构建 Cloudflare Workers 静态产物 (dist/server/index.js)
```
